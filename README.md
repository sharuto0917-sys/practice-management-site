# Bass Practice Management Site

エレキベースの練習管理を行うためのベースサイトです。

## 機能
- 練習者の一覧管理
- 今日の練習予定の登録
- 練習の完了/未完了切り替え
- BPM・練習時間・フレーズ記録の管理
- 今週の目標管理
- カテゴリ別フィルタリング
- ローカルストレージでデータ保存

## 使い方
1. `index.html` をブラウザで開く
2. 練習者を追加
3. 練習メニューを登録
4. 目標や練習記録を更新して管理

## 開発メモ
このサイトは、ベース練習の記録と進捗管理を手軽に行うためのベース版です。必要に応じて以下を拡張できます。
- 週次レポートの保存
- 曲ごとの練習ノート
- 練習動画や音源の埋め込み
- Firebase や Supabase によるクラウド同期
