# Bass Practice Management Site

エレキベースの練習管理を行うための本格版サイトです。

## 機能
- 練習者の一覧管理
- 練習メニューとカテゴリ別フィルタ
- 今週の目標管理
- 曲ごとの練習進捗管理
- BPM・練習時間・コメントの記録
- 日誌の追加と検索
- 週次・月次レポート表示
- ローカルストレージでデータ保存

## 使い方
1. `index.html` をブラウザで開く
2. 練習者を追加
3. 曲と練習メニューを登録
4. 練習記録や目標を更新して管理
5. 日誌や検索で振り返りを確認

## 開発メモ
このサイトは、ベース練習を継続的に管理するための本格版です。必要に応じて、以下を拡張できます。
- 月次レポートのグラフ化
- スケールの詳細トラッキング
- 練習日誌の検索とソート
- Firebase や Supabase によるクラウド同期
