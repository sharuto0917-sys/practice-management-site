# Bass Practice Management Site

エレキベースの練習管理を行うためのベースサイトです。

## 機能
- 練習者の一覧管理
- 今日の練習予定の登録
- 練習の完了/未完了切り替え
- BPM・練習時間・フレーズ記録の管理
- ローカルストレージでデータ保存

## 使い方
1. `index.html` をブラウザで開く
2. 練習者を追加
3. 練習メニューを登録
4. 完了状態や記録を更新して管理

## 開発メモ
このサイトは、ベースの練習管理を始めるためのシンプルなベース版です。必要に応じて以下を拡張できます。
- 曲ごとの練習メモ
- スケールの進捗管理
- 演奏動画のアップロード
- 週ごとの練習ログ分析
